# Learn.It.Simple / SQL Quest

A beginner-friendly SQL learning website for children, students, and career starters.

## What is included
- Complete SQL learning path from foundations to advanced topics, database design, performance, security, projects and interview practice.
- Child-friendly analogies and simple-English explanations.
- Four quizzes after every lesson: Easy, Medium, Hard, Hard.
- Full-width lesson view opened by clicking **Learn**.
- AI Teacher audio using the browser speech engine, with **Play** and **Stop** controls. The narration focuses on the “Think about it like this” explanation instead of reading the whole code block.
- Sign in / Login demo stored locally in the browser. This is not production authentication.
- Run Example button that sends a lesson query to the playground.
- SQL playground using SQL.js loaded from a CDN with a fallback CDN.
- Mobile-friendly layout.

## Run locally
Open `index.html` in a modern browser. For the SQL playground, the browser needs internet access so SQL.js can load from the CDN.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save and open the GitHub Pages URL.

## Important
The login feature is a local demo only. For a real website with user accounts, passwords, progress syncing, payments, and AI APIs, connect a backend such as Supabase or another secure authentication/database service.
